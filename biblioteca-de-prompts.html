BIBLIOTECA DE PROMPTS

Biblioteca de prompts gratuita: 90 prompts prontos para IA

Cada prompt resolve uma tarefa específica: organizar o dia, escrever um e-mail difícil, criar fórmula no Excel, preparar entrevista. Clique para ler o prompt completo ou copie direto — em ambos os casos você recebe as instruções de como preencher cada campo.

Como usar os prompts

Todo prompt daqui tem campos entre colchetes. Eles são o espaço onde você coloca a sua situação — e é isso que separa uma resposta genérica de uma resposta útil.

  • Ao copiar, abre a explicação de cada campo do prompt escolhido
  • Troque o conteúdo dos colchetes pelo seu contexto, com números sempre que tiver
  • Se a resposta vier vaga, diga para quem ela se destina e em que formato você quer
  • Não recomece do zero: peça o ajuste, como "deixe mais curto" ou "mude o tom"
  • Quando envolver dados, mantenha a instrução de usar apenas o que foi fornecido

Perguntas frequentes

A biblioteca é gratuita?

Sim. Os 90 prompts podem ser copiados e usados livremente, sem cadastro e sem limite.

Funciona em qualquer IA?

Sim. Todos foram escritos para funcionar no ChatGPT, Copilot, Claude e Gemini. Basta copiar e colar.

O que significam os campos entre colchetes?

São as informações que você substitui pelo seu contexto. Ao copiar ou abrir um prompt, cada campo aparece explicado com o que colocar ali.

Preciso usar o prompt exatamente como está?

Não. Use como ponto de partida. Acrescentar detalhes da sua situação sempre melhora a resposta.

O que faço se a resposta não vier boa?

Peça o ajuste em vez de recomeçar. Diga o que mudar: deixe mais curto, mude o tom, foque em determinado ponto.
